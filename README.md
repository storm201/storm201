## ⚡ Flagship Builds

<table>
<tr>
<td width="50%" valign="top">

### 🔎 [SourceShelf](https://github.com/storm201/sourceshelf)
**1,619 apps · 23 categories · 10 platforms**

Searchable catalog of installable open-source apps, re-crawled from the GitHub API **every night at 03:17 UTC**. **276 direct download links** resolved from real release assets.

- Zero-server: Actions crawl → build → commit → deploy
- Open submissions via issue template, auto-validated and merged
- Rate-limited? Falls back to scraping release pages
- 22 offline tests against a mock PostgREST server
- Vanilla JS, no frameworks, no trackers

`Python` `Supabase` `GitHub Actions` `Vanilla JS`

</td>
<td width="50%" valign="top">

### 🛰️ [GeoFUSE SentinelGuard](https://github.com/storm201/GEOFUSE)
**Smart India Hackathon 2026**

Super-resolution for Sentinel-2 imagery where every sharper tile ships with a **Trust Receipt**: a JSON of uncertainty, stability and spectral checks.

- Geographic hold-out split (no spatial leakage)
- **+0.49 dB PSNR · +0.0062 SSIM** over bicubic
- Reported with ΔNDVI and edge-F1, not buried under them
- PyTorch ensemble · FastAPI · React · Streamlit

`PyTorch` `FastAPI` `React` `Remote Sensing`

</td>
</tr>

<td width="50%" valign="top">

### 🌍 [ATLA](https://github.com/storm201/ATLA)
**Country intelligence platform**

REST Countries + World Bank merged into one analytics view: rankings, comparisons, and an interactive 3D globe.

- Two-layer cache: memory for speed, SQLite for durability
- Three.js globe · D3-Geo · Recharts radar comparisons
- Rate limiting, CORS, security headers, Waitress in prod
- 80% of the work was normalizing messy data

`React` `TypeScript` `Three.js` `Flask` `SQLite`

</td>
<td width="50%" valign="top">

### 🌿 [Growth Garden](https://github.com/storm201/Growth-Garden)
**Journaling where progress grows**

Goals, habits and memories become plants. Seedling → Sprout → Young Tree → Mature Tree based on how often you write.

- Four garden beds, per-plant timeline, photo gallery
- Cascading deletes so the DB doesn't rot
- Hand-written CSS, no framework

`Flask` `SQLAlchemy` `SQLite` `CSS`
